# 选中即译（Select Translate）

SillyTavern（酒馆）扩展：选中一段**非中文**文字，自动弹出**中文翻译**；选的是**日文**时，额外给出**罗马音（Romaji）**。

## 功能

- 选中文字（日文 / 英文 / 韩文等非中文）后，选区旁出现 **译** 小圆钮
- 点击弹出浮窗：
  - **原文**：你选中的内容（可复制）
  - **读音**：日文自动给罗马音；纯假名直接本地转换，含汉字时查 Jotoba 词典整词读音，整句未匹配时给出假名部分的罗马音并注明（可复制）
  - **译文**：中文翻译（可复制）
- 浮窗可拖动、可关闭（× / Esc / 点别处）
- 翻译源：谷歌翻译（自动识别语种）→ 失败自动切换 MyMemory
- 点击"译"时会自动重读当前选区，即使选完又挪动过也不会翻错文本

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.js` | 插件本体（单文件，无外部依赖） |
| `manifest.json` | 扩展清单 |
| `select-translate.user.js` | 油猴脚本版（不想装扩展就用它） |
| `demo.html` | 演示页，浏览器直接打开体验 |

## 安装

**方式一：扩展安装**
1. 把 `select-translate` 文件夹放进酒馆目录：
   ```
   public/scripts/extensions/select-translate/
   ```
   （或通过"扩展 → 安装扩展"粘贴你的仓库地址）
2. 刷新页面，扩展面板启用 **选中即译**。

**方式二：脚本导入（最快）**
1. 下载 `select-translate.user.js`
2. 酒馆 → 脚本管理 → 全局脚本 → **导入** → 选择该文件 → 启用
3. 刷新聊天页即可

## 使用

1. 在聊天里**选中**一段日文/英文等文字（按住拖动选择）
2. 选区旁边出现 **译** 按钮，点它
3. 浮窗里看译文和罗马音；点"复制"一键复制

## 兼容性

纯 DOM + fetch 实现，不依赖酒馆内部 API；桌面版、手机版通用。
